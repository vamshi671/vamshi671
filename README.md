### Systolic Array MAC Accelerator – Full ASIC Design (RTL-to-GDSII)
**Verilog | Yosys | OpenLane | SKY130**

- Designed a 4×4 weight-stationary systolic array MAC accelerator for 8-bit integer matrix multiplication with 18-bit accumulation
- Executed complete RTL-to-GDSII flow – Yosys synthesis (5,683 cells), OpenLane/OpenROAD place-and-route, CTS, and TritonRoute targeting SkyWater 130nm at 50 MHz
- Achieved DRC-clean and LVS-clean layout (0 violations) with timing closure (WNS = 0.0 ns) on a 500×500 µm die at 50% utilization

</td>
</tr>

<tr>
<td>

### Real-Time Sleep Apnea Detection via Respiratory Acoustic Analysis
**Python | Raspberry Pi | ML**

- Built a non-contact sleep apnea detection system analyzing respiratory audio in real time on a Raspberry Pi
- Extracted MFCC features using Librosa and trained a Random Forest classifier achieving **85% accuracy** and **91% recall**
- Optimized on-device inference to run in ~120 ms per frame for fully offline edge detection

</td>
</tr>

<tr>
<td>

### Breath VOC Electronic Nose (E-Nose) for Diabetes Screening
**Python | Raspberry Pi | ML**

- Developed a portable electronic nose using MQ-series gas sensors to detect elevated acetone in breath as a non-invasive diabetes indicator
- Implemented Raspberry Pi-based data acquisition with ADS1115 16-bit ADC across structured trial protocols
- Trained a calibrated Gradient Boosting classifier achieving **87.5% accuracy** and **0.87 AUC** with Leave-One-Out cross-validation

</td>
